# T1 验证步骤：网页视图遥控器可用

> 目标：只用遥控器，在「粤漫之家」上完成
> **聚焦站点搜索框并输入 → 展开分类菜单 → 进入一部动画详情页 → 返回上一页**。
> 全程不碰鼠标、不碰触屏、不用 `adb` 注入点击（`adb` 只用来发遥控器按键和截图）。

## 1. 安装与进入

```bash
adb connect 127.0.0.1:16384          # MuMu；真机换成自己的 IP / 序列号
adb -s 127.0.0.1:16384 install -r TVWebPlayer/dist/TVWebPlayer-0.5.0-debug.apk
```

打开 App → 首页站点列表 → 方向键选「粤漫之家」→ **确认** → 进入网页视图
（默认就是网页视图，站点原样加载，顶部有搜索框、分类、登录入口）。

## 2. 遥控器按键表

| 键 | 作用 |
|---|---|
| 方向键 | 空间导航（几何最近邻移动焦点） |
| 确认 / Enter | 派发真实触摸，点击当前焦点 |
| 菜单键 | 唤出工具条（首页 / 整理视图 / 缩放 / 指针模式 / 刷新） |
| 返回键 | 键盘 → 弹层 → 网页历史 → 站点首页 → 站点列表 |
| 缩放 +/- | 100 / 125 / 150 三档，按站点分别记住 |

## 4. 已知限制（如实说明，不伪装成完成）

1. **系统软键盘唤不起**：MuMu / 部分盒子上，应用内派发的触摸不经过系统输入通道，
   WebView 不建立 Android 编辑态，`showSoftInput` 无效（对照实验：系统级
   `adb input tap` 同坐标能让 `mInputShown=true`，应用内派发为 `false`）。
   第三方应用拿不到 `INJECT_EVENTS` 权限，绕不过。
   → 已改为 **App 内置遥控器键盘**，文字经 JS 原生 setter + `input` 事件写入，
   React/Vue 都能感知。
2. **内置键盘只直接支持 ASCII**：中文请用「粘贴」读剪贴板，或点「系统键盘」
   在真机上切到 IME。没有做拼音/手写，那需要真正的输入法引擎，超出 T1 范围。
3. **跨域 iframe**：受同源策略限制，主 frame 只能把 iframe 整体当焦点目标，
   进入后由该 frame 自己注入的脚本接管方向键。不做任何绕过。
   该站点没有 iframe 页面，这一分支**未在真机/模拟器实测**。
4. **`DOCUMENT_START_SCRIPT` 特性**：老系统 WebView 不支持时，注入退回
   `onPageFinished`，只覆盖主 frame，界面会明确提示。本次环境支持该特性。
